# 桌面界面规范

本阶段沿用 Vue 3 与 Element Plus，不改变业务权限与写入规则。

| 项目 | 规范 |
| --- | --- |
| 主色 | `#315eaa`，用于选中导航、主按钮及链接 |
| 背景 / 表面 | `#f4f6fa` / 白色 |
| 正文 / 次级 / 边框 | `#22324a` / `#65748a` / `#dfe5ee` |
| 语义色 | 成功绿 `#36836f`；警告棕 `#b7791f`；错误红 `#c25555` |
| 字体 | 系统字体及 Microsoft YaHei；正文14px、表格13px、标题26px |
| 布局 | 侧栏224px，窄桌面190px；顶部66px；内容最大1600px；桌面内边距32px |
| 间距 / 圆角 | 模块16–24px；表面22px内边距；6–8px圆角 |
| 表格 | 统一表头与边框、内部横向滚动、右侧固定操作列；不一次绘制所有名单 |
| 状态 | 文字与标签同时表达，不能只依赖颜色；缺考与真实零分区分 |
| 弹窗 | 保留已有适配视口宽度，最大90vh且内部滚动；写入不允许遮罩误关闭 |
| 交互 | 主操作使用主色，其余普通/链接按钮；请求期间禁用重复提交；明确确认删除 |

共享入口：`frontend/src/styles.css`；业务补充：`views/business.css`。复用 `MetricCard`、`StatusTag` 和原 Element Plus 表格、表单、对话框、分页、通知、加载及空状态。

图表不使用模拟数据。考勤SVG随容器伸缩，无第三方图表实例或销毁问题，并提供可展开数据表。作业分布沿用 `el-progress`，同时展示数量。AI表格使用已授权工具实际返回的数据，不解析模型文字充当数据库结果；模型完整回答不作为成功写入凭据。

键盘可聚焦导航、表单、弹窗及详情展开项；AI支持Enter发送、Shift+Enter换行，兼容Ctrl/⌘+Enter发送，中文输入法选词时不发送。尊重系统减少动画设置。

侧栏按任务分组。「班级与学生」在内容区切换学生名单和班级列表，「日常记录」切换考勤、作业和表扬。首页、成绩管理、AI 班级助手及管理员回收站保留直接入口。子页地址继续使用原有 `view` 值，刷新后仍在当前子页。手机端主导航按三列排列。

AI 对话页采用 ChatGPT 式窄幅阅读区与底部组合输入框，沿用蓝色及 Element Plus。以教师日常操作为主，视觉变化3/10、动效2/10、信息密度4/10：移除重复说明和整页消息卡片，查询表格按需展开，附件工具默认收起；空白、等待、失败均显示真实状态。请求失败保留问题和附件，不自动重发写入指令。桌面使用独立对话滚动区，手机导航横向滚动，输入框保持可见。

回收站沿用相同设计取值与Element Plus，以分类筛选、来源、删除时间及单条/整组恢复为主。恢复前展示目标及关联数量，冲突显示后端原因；AI删除/恢复预览按数据类型显示影响数量，确认和取消状态可见。手机表格内部横向滚动，取消固定操作列避免遮挡主要数据。

## 学科主题美化包

顶部「学科主题」可打开主题选择面板，提供语文、数学、英语、物理、化学、生物、历史、地理、政治、体育、音乐、美术、信息技术共 13 套主题，以及默认主题恢复入口。选择立即生效，保存在本机 localStorage，不写业务数据库。

2026-10-26 根据用户反馈，将视觉方向从生成的 3D 微缩陈列改为课本封面：纸面浅色、宋体学科标题、窄书脊色带、图文分区。语文使用萧云从的真实水墨画，生物使用植物学版画，历史使用青铜鼎馆藏照片，美术使用莫奈真实画作；四份均为 Cleveland Museum of Art 的 CC0 素材。其余九科使用准确公式、符号、实验/经纬网/田径场示意图、乐谱和文字排版，不使用生成场景图。来源和内容说明见 frontend/public/theme-covers/README.md。

现有 Vue 3 与 Element Plus 保留，不引入新依赖。主题限定为模拟纸面印刷的浅色风格，侧栏也改为浅色；不增加深色模式，不叠加渐变蒙版、玻璃质感、浮动或缩放动画。视觉变化 5/10、动效 1/10、密度 4/10。原有成功、警告、错误语义色与业务操作不变。

SubjectCover.vue 是实际的可复用封面组件，用于选择面板、当前预览和页面横幅。首页采用横向封面，业务页采用紧凑封面，AI 页保留完整对话空间。桌面书架三列，中等宽度两列，手机面板上下排列且书架两列；底部状态和完成按钮始终在弹窗可视区域。

实现文件：frontend/src/subject-themes.js、frontend/src/subject-themes.css、frontend/src/components/SubjectCover.vue、SubjectThemePicker.vue、SubjectThemeBanner.vue。素材为 frontend/public/theme-covers/ 中的四份 WebP 和九份 SVG。旧生成素材保留但不再引用。

验证：项目根目录运行 node frontend/src/subject-themes.test.mjs；前端目录运行 npm run build。主题逻辑测试包含 13 个学科、素材存在、按钮和纸面文字对比度、公式/乐谱内容、默认恢复及存储不可用回退。浏览器使用独立测试响应验证视觉与切换，不代表真实数据库或模型联调。
